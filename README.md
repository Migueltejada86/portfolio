# Portfolio Miguel Angel Tejada

Portafolio profesional estático de Miguel Angel Tejada — Python Developer | AI Agents | Cybersecurity.

## Stack

- HTML + Tailwind CSS (CDN, sin build step)
- JavaScript vanilla mínimo
- Deploy: GitHub Pages, Netlify o Vercel

## Estructura

```
portfolio/
├── index.html          # Página principal
├── js/
│   └── main.js         # Filtros de proyectos
├── casos/
│   ├── vulpy.html
│   ├── gendo.html
│   └── ultron.html
├── assets/             # Imágenes (opcional)
└── README.md
```

## Cómo actualizar

1. Editar textos directamente en los HTML.
2. Agregar nuevos proyectos: copiar una card en `index.html` y crear un caso en `casos/` si es necesario.
3. Subir a GitHub y activar Pages (o conectar a Netlify/Vercel).

## Deploy rápido (GitHub Pages)

1. Crear repo `portfolio` (o el nombre que quieras).
2. Subir estos archivos a la rama `main`.
3. Settings → Pages → Source: Deploy from branch → main / root.
4. Listo: `https://Migueltejada86.github.io/portfolio/`
