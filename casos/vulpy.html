CASO DE ESTUDIO · APPSEC

Vulpy

Pipeline multi-agente de AppSec que genera parches a partir de hallazgos de SAST.

Problema

Los desarrolladores y equipos pequeños pierden tiempo revisando hallazgos de herramientas SAST. Semgrep detecta vulnerabilidades, pero no explica el impacto en lenguaje claro, no genera el parche y no propone tests de regresión. El resultado: deuda de seguridad que se acumula.

Solución

Vulpy orquesta 4 agentes:

  • Detector: ejecuta Semgrep sobre el código.
  • Explainer: usa GPT-4 para explicar la vulnerabilidad con contexto OWASP/CWE en español.
  • Patcher: genera un parche en formato diff.
  • Tester: propone tests pytest para validar el fix.

El flujo es end-to-end: del hallazgo al parche listo para revisar.

Stack

Python Semgrep OpenAI GPT-4 pytest OWASP / CWE

Impacto

  • Reduce el tiempo de triaje de hallazgos de minutos a segundos.
  • Genera parches y tests accionables en lugar de solo alertas.
  • Documentación y explicación en español, pensada para equipos locales.
  • Base para integrar como gate de seguridad en CI/CD (roadmap v2).
